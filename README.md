# TerraCost

해외여행 비용 관리 웹 애플리케이션 — 환율 계산, 팁 계산, 여행 경비 계산, 여행 지출 노트를 하나의 `index.html`로 제공합니다.

## 실행
설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 주요 기능
- **환율 계산기** — 사칙연산·괄호·% 계산기, 8개 통화, 실시간 환율(open.er-api.com) + 연결 실패 시 샘플 환율
- **팁 계산** — 국가별 통화, 팁 비율 직접 입력/빠른 선택, 팁·최종 금액 계산
- **여행 경비 계산** — 국가·도시·기간 선택, 숙박(1박)·식비(1끼)·교통(1km) + 기타 항목, 입력 즉시 합산
- **여행 지출 노트** — 월간 달력, 날짜별 지출 추가·수정·삭제
- **설정** — 7개 언어(한국어, English, 日本語, 中文, Español, Français, Deutsch), 계정·기본 통화
- 모든 데이터는 브라우저 LocalStorage에 저장되어 새로고침 후에도 유지

## 반응형
휴대폰(~767px) · 세로 태블릿(768px~) · 가로 태블릿/노트북(1024px~) · 데스크톱(1100px~) 전용 레이아웃

## 기술
HTML5 · CSS3 · Vanilla JavaScript (단일 파일, 서버 불필요)
